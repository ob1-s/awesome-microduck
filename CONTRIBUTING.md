# Contributing to Awesome MicroDuck

One PR, one line, one link.

**Format:**
```
- [Project Name](https://github.com/you/repo) — One sentence, what it does for MicroDuck.
```

**Rules:**
1. Put it in the right section (Games / Sim & Tools / VR & Teleop / Integrations / Hardware / Community Policies / Learning). Create a new section if it truly doesn't fit.
2. Alphabetical within the section (case-insensitive).
3. Link must be live and open (repo, HF Space, blog post). No dead `docs/models/...` links.
4. No affiliate spam. If it's yours, say so — that's fine.
5. Squash to one commit: `add: My Cool Duck Game`.

We merge quickly if you follow the format — no need to ask.

*For ONNX policies, use [uDuck Registry](https://github.com/ob1-s/uduck-registry) instead — this list is for games, tools, VR, and parts around the duck.*
